## 附：复现方法

报告日期是**本地日期**（中国标准时间），而 `trades.ts` / `events.ts` 存的是 UTC。所以下面的窗口是本地这一天对应的 UTC 区间：`2026-11-21T16:00:00Z` ~ `2026-11-22T16:00:00Z`。

```sql
-- 今日平仓明细
SELECT id, ts, side, price, qty, pnl, source, order_id
FROM trades
WHERE ts >= '2026-11-21T16:00:00' AND ts < '2026-11-22T16:00:00' ORDER BY ts;

-- 今日汇总
SELECT COUNT(*) AS n,
       SUM(CASE WHEN pnl > 0 THEN 1 ELSE 0 END) AS wins,
       ROUND(SUM(pnl), 4) AS net_pnl
FROM trades WHERE ts >= '2026-11-21T16:00:00' AND ts < '2026-11-22T16:00:00';

-- 累计已实现盈亏（排除回填行）
SELECT COALESCE(SUM(pnl), 0) FROM trades
WHERE order_id IS NULL OR order_id NOT LIKE 'backfilled_%';

-- 今日事件
SELECT ts, level, msg FROM events
WHERE ts >= '2026-11-21T16:00:00' AND ts < '2026-11-22T16:00:00' ORDER BY id;
```
